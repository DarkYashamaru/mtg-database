# mtg-database

A Magic: The Gathering card database built on data from Scryfall.

This project's primary purpose is to fetch, store, and keep card data synchronized with the latest information available from Scryfall. On its own, it provides a maintained card database and is intended to serve as a foundational component for other applications and services.

## Data Sources

This project uses data provided by Scryfall.
